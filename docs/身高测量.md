# HC-SR04 + DS18B20 身高测量

## 1. 接线

STM32F103 开发板、HC-SR04、DS18B20 和外置 CH340 USB-TTL 模块必须共地。

| 器件 | 器件引脚 | STM32F103 开发板 |
|---|---|---|
| HC-SR04 | VCC | 5V |
| HC-SR04 | GND | GND |
| HC-SR04 | Trig | PB9 |
| HC-SR04 | Echo | PB8（TIM4_CH3） |
| DS18B20 | VDD | 3.3V |
| DS18B20 | GND | GND |
| DS18B20 | DQ | PB5，并用 4.7kΩ 上拉到 3.3V |
| CH340 | TXD | PA10（STM32 USART1_RX） |
| CH340 | RXD | PA9（STM32 USART1_TX） |
| CH340 | GND | GND |
| CH340 | VCC / 5V / 3.3V | 不接 |

PB8 是 5V 容忍数字引脚，可接 HC-SR04 的 5V Echo；建议串联 330Ω 保护电阻。
DS18B20 必须采用 VDD、DQ、GND 三线供电，本驱动不支持寄生供电。

### 1.1 USB 连接与供电

本方案使用两根 USB 线，将供电和烧录分开：

1. 开发板自身的 Micro-USB 连接笔记本电脑，只负责给开发板和传感器供电。
2. 外置 CH340 模块连接笔记本电脑，负责 FlyMcu 串口烧录。
3. CH340 的供电脚不要连接开发板，避免与开发板 Micro-USB 重复供电。
4. 即使两者连接同一台电脑，CH340 GND 仍需连接开发板 GND，作为串口信号参考地。

开发板照片中的 Micro-USB 是 STM32 原生 USB 接口，不是板载 CH340；烧录必须使用外置
CH340 模块连接 PA9/PA10。

## 2. 安装与标定

HC-SR04 固定在人体上方，探头垂直朝下。用卷尺测量“超声波探头发射面到地面”的距离，
单位为 mm。构建参数 `HCSR04_INSTALL_HEIGHT_MM` 用来设置该值，默认值为 2000。

计算关系：

```text
声速 = 331.3 + 0.606 × 温度(°C)
头顶距离 = Echo高电平时间 × 声速 ÷ 2
身高 = 安装高度 - 头顶距离
```

固件连续采集 5 次，间隔 60ms，取有效样本中值。如果有效样本少于 3 次则返回超时；
样本最大差值超过 30mm 则返回不稳定。

## 3. 构建固件

先按照 [开发环境搭建](开发环境搭建.md) 配置工具链并获取 STM32CubeF1 HAL，然后从项目根目录运行：

```bash
cmake --preset stm32 -DMODULE_SET=chafanting \
      -DHCSR04_INSTALL_HEIGHT_MM=2000
cmake --build --preset stm32
```

将 `2000` 替换成实际安装高度。生成文件位于 `build/stm32/firmware.elf`、
`build/stm32/firmware.bin` 和 `build/stm32/firmware.hex`。

## 4. 使用 FlyMcu 手动烧录

工程不启动或修改 FlyMcu。每次构建后，在 FlyMcu 中手动选择：

`build/stm32/firmware.hex`

然后：

1. 将 CH340 插入电脑，在 FlyMcu 中选择 `USB-SERIAL CH340 (COMx)` 对应的 COM 口；
   芯片类型选择 STM32，并启用编程后校验。
2. 将开发板 `BOOT0` 接 3.3V、`BOOT1/PB2` 保持低电平，然后按一下 RESET 或重新上电。
3. 在 FlyMcu 中开始 ISP。若一直等待同步，在提示后再按一次 RESET。
4. 烧录成功后，将 `BOOT0` 接回 GND，再按 RESET 运行固件。
5. USART1 使用 115200 8N1；成功日志中 `height primary=1732` 表示身高 1732mm，
   `secondary=2531` 表示温度 25.31°C。

FlyMcu 使用 STM32 ROM 内置的 USART Bootloader，因此可以烧录但不能像 ST-Link 一样单步或断点调试。
烧录时不要同时打开串口助手，否则 COM 口会被占用。

## 5. 常见问题

- `TIMEOUT`：检查 HC-SR04 供电、共地、Trig/Echo 是否接反；检查 DS18B20 的 4.7kΩ 上拉。
- `UNSTABLE`：保持站立、头顶正对探头，并避免旁边物体进入超声波波束。
- 固定偏差：重新测量安装高度；探头外壳到实际发射面的机械偏移也应计入标定。
- 偶发 CRC 错误：缩短 DS18B20 线长、检查上拉电阻和共地，避免与 HC-SR04 电源线并行过长。
- FlyMcu 无法连接：确认 CH340 TXD→PA10、RXD→PA9、GND 已连接，BOOT0 为高，
  并排除选到了蓝牙虚拟串口。
