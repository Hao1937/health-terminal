# 硬件接线与上电检查

## 1. 硬件清单

本人负责部分使用：

- STM32F103C8T6 开发板；
- SSD1306 128×64 I2C OLED，地址 `0x3C`；
- 4×4 矩阵键盘；
- MPU6050 模块，地址 `0x68`；
- 独立 LED 与限流电阻；
- 独立常开按键；
- ESP32 DEVKIT V1 / ESP-WROOM-32；
- ST-Link、USB 数据线和必要的杜邦线。

整机最终接线必须以 `core/include/board.h` 和 `docs/引脚分配表.md` 为准。

## 2. 接线总表

| 模块 | 模块端 | STM32/ESP32 端 | 说明 |
| --- | --- | --- | --- |
| OLED | SCL | STM32 PB6 | I2C1 SCL |
| OLED | SDA | STM32 PB7 | I2C1 SDA |
| OLED | VCC | 按模块规格接 3.3V | 优先 3.3V 逻辑 |
| OLED | GND | STM32 GND | 共地 |
| MPU6050 | SCL | STM32 PB6 | 与 OLED 共用 I2C1 |
| MPU6050 | SDA | STM32 PB7 | 与 OLED 共用 I2C1 |
| MPU6050 | VCC | 按模块规格接 3.3V | 确认载板稳压及电平 |
| MPU6050 | GND | STM32 GND | 共地 |
| 键盘 | R1/R2/R3/R4 | PB12/PB13/PB14/PB15 | 行输出 |
| 键盘 | C1/C2/C3/C4 | PA4/PA5/PA6/PA7 | 列输入上拉 |
| 反应 LED | 正极 | PB1，经限流电阻 | 高电平点亮 |
| 反应 LED | 负极 | GND | 建议串 220～1kΩ 电阻 |
| 反应按键 | 一端 | PB0 | 内部上拉、下降沿 EXTI0 |

## 3. I2C 总线注意事项

OLED 和 MPU6050 共用：

```text
I2C1 SCL = PB6
I2C1 SDA = PB7
速率 = 100 kHz
```

设备地址不冲突：

```text
OLED     0x3C
MPU6050  0x68
```

建议：

1. 总线只保留一组约 4.7kΩ 上拉到 3.3V；很多模块载板已经自带上拉，先检查再并联；
2. SCL/SDA 不要接反；
3. 杜邦线尽量短；
4. 所有模块必须与 STM32 共地；
5. 如果 OLED 正常但 MPU6050 超时，优先检查地址、供电、AD0 和接线；
6. 如果两个模块都不响应，优先检查 PB6/PB7、共地和上拉。

## 4. 4×4 键盘排线确认

不同厂家键盘的 8 针排线顺序可能不同，不能仅按外观猜测。应先用万用表通断档确认行列，再对应：

```text
ROW0 → PB12
ROW1 → PB13
ROW2 → PB14
ROW3 → PB15
COL0 → PA4
COL1 → PA5
COL2 → PA6
COL3 → PA7
```

软件期望的物理布局：

```text
1  2  3  A
4  5  6  B
7  8  9  C
*  0  #  D
```

若按键显示错位，通常是排线行列顺序与上述定义不一致，不要先修改软件映射；先确认实际引脚。

## 5. 反应 LED 与按键

参考接法：

```text
PB1 ── 限流电阻 ── LED 正极
LED 负极 ───────── GND

PB0 ── 常开按键 ── GND
```

代码把 PB0 配置为内部上拉和下降沿中断，因此：

- 未按：PB0 为高；
- 按下：PB0 被拉低，触发 EXTI0；
- 不需要把 PB0 接 5V；
- 独立 LED 不是 PC13 板载状态灯。

## 6. ESP32 供电与串口

推荐：

```text
ESP32 使用自己的 USB 线独立供电
STM32 使用自己的供电/ST-Link
两块板 GND 相连
PA2 → GPIO16
```

不要把 STM32 的小功率 3.3V 输出同时接到已经由 USB 供电的 ESP32 `3V3`。不要把 5V UART 信号接入 GPIO16。不要使用 ESP32 的 GPIO3/RX0 和 GPIO1/TX0，它们通常用于 USB 下载与调试；本网关使用 UART2 的 GPIO16/17。

## 7. 上电前检查清单

- [ ] PA13/PA14 保留给 SWD，没有被模块占用；
- [ ] OLED 与 MPU6050 的 SCL/SDA 未接反；
- [ ] I2C 上拉接到 3.3V，而不是 5V；
- [ ] 键盘 8 线行列已用万用表确认；
- [ ] PB1 LED 已串限流电阻；
- [ ] PB0 按键按下时接地；
- [ ] STM32 PA2 接 ESP32 GPIO16；
- [ ] STM32 与 ESP32 共地；
- [ ] ESP32 使用稳定 USB 供电；
- [ ] 没有把外部 5V UART 直接接入 MCU GPIO。

## 8. 上电后的快速判断

| 现象 | 优先检查 |
| --- | --- |
| OLED 无任何显示 | 0x3C、PB6/PB7、供电、上拉 |
| OLED 有菜单但按键错位 | 键盘排线顺序 |
| 所有按键无效 | PB12-15、PA4-7、共地、`MODULE_SET` |
| Reaction 一直提示松开 | PB0 被持续拉低或按键接错 |
| MPU TIMEOUT | MPU6050 地址、AD0、供电、I2C |
| ESP32 系统蓝牙可见但网页找不到 | 使用最新版网页，设备选择器中手动选 `HealthTerminal-Gateway` |
| ESP32 周期消失/重启 | USB 线、电源能力、brownout |
