# OLED 多级菜单与矩阵键盘复现

## 1. 设计目标

`ui_flow` 负责：

- OLED 当前显示什么；
- 读取并解释矩阵键盘；
- 菜单内部层级切换；
- 将真正的“测量”或“上传”动作返回给主状态机。

`app_statemachine` 继续负责传感器调用、记录更新、评分、BLE 和 Flash，从而避免 UI 直接依赖所有驱动。

接口定义：

```c
typedef enum {
  UI_ACT_NONE = 0,
  UI_ACT_MEASURE,
  UI_ACT_UPLOAD,
} ui_action_t;
```

代码位置：`app/ui_flow.c`、`app/ui_flow.h`。

## 2. 键盘矩阵

软件映射：

| | COL0 PA4 | COL1 PA5 | COL2 PA6 | COL3 PA7 |
| --- | --- | --- | --- | --- |
| ROW0 PB12 | `1` | `2` | `3` | `A` |
| ROW1 PB13 | `4` | `5` | `6` | `B` |
| ROW2 PB14 | `7` | `8` | `9` | `C` |
| ROW3 PB15 | `*` | `0` | `#` | `D` |

扫描方式：

1. 所有行先拉高；
2. 逐行拉低；
3. 等待约 2µs；
4. 检查哪一列为低；
5. 扫描完恢复所有行高电平。

消抖方式：

- 15ms 时间消抖；
- 稳定状态发生变化后才确认；
- 一次按下只返回一次；
- 长按不重复上报。

当前不支持多键组合、长按连发或防鬼键；同时按多键时只返回扫描到的第一个键。

## 3. 按键定义

### 3.1 主导航键

| 键 | 功能 |
| --- | --- |
| `A` | 确认、进入 |
| `B` | 返回上一级 |
| `C` | 上一项 |
| `D` | 下一项 |
| `1`～`7` | 从任意菜单页面直接跳到对应根菜单项 |

### 3.2 备用导航键

为了在部分键盘第 4 列接触不稳定时仍能操作，软件提供：

| 键 | 等价键 | 功能 |
| --- | --- | --- |
| `8` | `A` | 确认/进入 |
| `9`、`*` | `B` | 返回 |
| `0`、`#` | `D` | 下一项/切换 |

### 3.3 各页面行为

| 页面 | `A` | `B` | `C` | `D` |
| --- | --- | --- | --- | --- |
| 根菜单 | 进入当前项 | 无 | 循环上一项 | 循环下一项 |
| Start/Back | 执行选项 | 回根菜单 | 切换选项 | 切换选项 |
| History 列表 | 看详情 | 回根菜单 | 上一记录 | 下一记录 |
| History 详情 | 看当前指标趋势 | 回列表 | 上一指标 | 下一指标 |
| History 趋势 | 无 | 回详情 | 无 | 无 |

## 4. 菜单结构

根菜单共 7 项：

```text
1.Height/Weight
2.HR/SpO2
3.Balance
4.Grip
5.Reaction
6.Score/Upload
7.History
```

层级：

```text
根菜单
├─ 1.Height/Weight ─ Start / Back
├─ 2.HR/SpO2      ─ Start / Back
├─ 3.Balance      ─ Start / Back
├─ 4.Grip         ─ Start / Back
├─ 5.Reaction     ─ Start / Back
├─ 6.Score/Upload ─ Start / Back
└─ 7.History
   └─ 历史列表（每屏最多 6 条，默认从最新记录开始）
      └─ 记录详情
         └─ 单指标趋势曲线
```

> 源码中 `s_hist_sel` 的注释写成了 `0=最旧`，但实际读取使用 `count - 1 - s_hist_sel`，所以 UI 默认选中的是最新记录。本文按实际行为说明。

## 5. History 详情和趋势指标

详情页支持切换：

```text
HEIGHT
WEIGHT
BMI
BODYFAT
HR
SPO2
BALANCE
GRIP
REACTION
SCORE
```

趋势读取最近最多 80 条历史，跳过：

- Flash 读取失败的记录；
- 对应字段为 `HS_VALUE_INVALID` 的记录。

如果没有有效数据，显示：

```text
NO DATA
```

## 6. OLED 实现说明

屏幕参数：

```text
SSD1306
128×64
8 pages
I2C 0x3C
5×7 字体
每行最多约 21 字符
```

支持：

- 普通文本；
- 整行反白选中；
- 当前记录六行概览；
- 最多 80 点的折线趋势。

字库只包含数字、英文字母以及 `. : - % /` 等少量符号；小写自动转大写，未覆盖字符显示为空格，不支持中文。

趋势图方法：

1. 计算当前序列最小值和最大值；
2. 横坐标按样本顺序均匀铺开；
3. 纵坐标按当前序列范围归一化；
4. 相邻点连线，并以小十字标记样本；
5. 常量序列显示在图中央。

当前趋势图没有时间刻度、固定量程、单位标签或异常值滤波。

## 7. 复现步骤

1. 使用 `MODULE_SET=liuyanming` 或 `full` 编译并烧录；
2. 上电确认显示 7 项根菜单；
3. 逐个按 `C/D`，确认反白条循环移动；
4. 按 `A` 进入，确认 `Start/Back`；
5. 用 `8/9/0` 再操作一次，确认备用键有效；
6. 在任意非根页面按 `1`～`7`，确认直接跳转；
7. 完成至少两次有效测试并上传/存储；
8. 进入 `7.History`，检查列表、详情、指标切换和趋势；
9. 重启设备，确认 Flash History 仍可读取。

## 8. 验收标准

- [ ] 16 个物理键映射与表格一致；
- [ ] 按一次只触发一次，长按不连发；
- [ ] `A/B/C/D` 和备用键均可导航；
- [ ] 菜单切屏无上一页残影；
- [ ] History 默认显示最新记录；
- [ ] 详情可循环 10 个指标；
- [ ] 无效数据不会把趋势图拉成异常尖峰；
- [ ] 断电重启后 Flash 历史仍存在。
