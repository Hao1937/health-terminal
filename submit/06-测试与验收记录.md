## 2. 自动构建与测试

### 2.1 Host

```powershell
cmake --preset host
cmake --build --preset host
ctest --preset host --output-on-failure
```

结果：

```text
cmake --preset host：配置通过。
cmake --build --preset host：失败，当前 MSVC 环境找不到标准头文件
（stddef.h、stdint.h、math.h、string.h），属于本机工具链环境问题，未声称测试通过。
ctest 未执行（因构建失败）。
```

覆盖：filters、codec、algorithms。未覆盖硬件驱动和浏览器。

### 2.2 本人模块固件

```powershell
cmake --preset stm32 -DMODULE_SET=liuyanming
cmake --build --preset stm32
```

结果：

```text
通过：MODULE_SET=liuyanming，固件链接成功。
FLASH 28272 B / 60 KB（46.02%）；RAM 5864 B / 20 KB（28.63%）。
```

确认 CMake 输出中包含：

```text
oled keypad reaction ble storage mpu6050
```

### 2.3 整机固件

```powershell
cmake --preset stm32 -DMODULE_SET=full
cmake --build --preset stm32
```

结果：

```text
通过：MODULE_SET=full，固件链接成功。
FLASH 30380 B / 60 KB（49.45%）；RAM 7488 B / 20 KB（36.56%）。
```

### 2.4 格式检查

CI 会对 C/H 文件执行 clang-format 检查，并对 algorithms 执行 clang-tidy。正式提交前按仓库 `.clang-format`
对最终纳入提交的源码复查；未实际执行的检查必须保留为“待验证”。

结果：

```text
C/H 变更文件：clang-format 19.1.7 dry-run --Werror 通过（待最终提交集复查）
algorithms clang-tidy：待验证
```
